# Certification requirements

Reference for the cert rules in the prototype (R10 and R11). The data lives in
`src/persistence/seed.js`.

## Certs by role

| Role | Food Handler Card | Medical Health Card | Hygiene Refresher Training | Alcohol Server Certification | Allergen Awareness Training | Food Manager Certification |
|---|---|---|---|---|---|---|
| Cook / prep | ✓ | ✓ | ✓ | | | |

| Server | ✓ | ✓ | ✓ | ✓ | ✓ | |
| Bartender / barback | ✓ | ✓ | ✓ | ✓ | ✓ | |
| Host | | | | only if checking IDs | ✓ | |
| Door / security | | | | ✓ | | |
| Manager / shift lead | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

## When you need it and how often it renews

| Cert | Needed by | Renew every |
|---|---|---|
| Food Handler Card | 30 days after starting | 3 years |
| Medical Health Card | first shift | 1 year |
| Hygiene Refresher Training | first shift | 2 years |
| Alcohol Server Certification | 60 days after starting | 3 years |
| Allergen Awareness Training | 30 days after starting | 3 years |
| Food Manager Certification | first shift managing | 5 years |
| First Aid / CPR Certification | before counting as the first aid person | 2 years |

## Every shift also needs

- At least one person on site with First Aid / CPR.
- A certified Food Manager on site the whole time.

## Grace periods

New hires can work without a cert until their 30 or 60 days are up. After
that, or if a cert expires, they can't work that role until they get it.
Renewals don't get a grace period.
