ShiftChex Sign in

Restaurant scheduling that checks the rules for you

Every time a manager puts someone on a shift, ShiftChex checks it against their availability, time off, rest between shifts, under 18 limits and certifications. A week can't go out while anything on it breaks a rule.

Try the demo See the code

The demo fills in the sign in for you, as the manager or any employee. Everyone in it is made up.

Rules checked as you build

Eleven rules run on every change. Some block publishing, some just warn, and a manager can override availability with a reason on record.

Shift swaps that stay legal

Staff post shifts they can't make. Anyone who'd break a rule by taking one can see why, and the check runs again when the manager approves.

Certifications on the calendar

Alcohol, food handler and first aid certs are checked against the date of each shift, so a card that runs out next Thursday is caught now.

Coverage and labor at a glance

A weekly report shows open shifts, labor against the budget, who's close to overtime and which certs come due next.
